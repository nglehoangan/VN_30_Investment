The owner's exact request is retained in OWNER_REQUEST.txt and its hash-bound authorization in SOURCE_POLICY_AUTHORIZATIONS.json. This authorizes standing CaféF raw close and standing financial-source admission for **Current Formal Valuation**, automatic transformation/validation/replay, and unchanged strict publication requirements for Historical PIT. It does not approve arbitrary records, the pending VNM17 facts, code integrity or production activation.

## Automatic admission and requalification

Trusted server composition supplies active owner authorization and independently accepted exact material references. The source registry checks original request/authorization hashes, policy identity/version, current code and source bindings, reviewer identity, acceptance time and supersession. An input JSON cannot enroll its own PASS/approved flags. The financial source bundle also binds retained extraction/review identity; original qualified review can be reused without another owner source approval. New material requires integrity/semantic verification, not a repeated approval of the unchanged source principle.

Per-observation checks remain mandatory. Raw/native identity, exact period/frame, ticker, scope, source role, document type, unit, numeric conversion, qualified extraction, conflicts, chronology and replay must pass. Missing raw, unknown mappings/units, changed schema or unresolved conflicts quarantine the affected request. Default operation has no invented independent acceptance record. DI14/DI15 and analytical/sector contracts outside this bounded source policy are not silently waived.

## Purpose and time amendment

`current-formal-evidence-time-v1` is a new explicit time contract, accepted by `validateEvidence` only when the caller requests `CURRENT_FORMAL_VALUATION`. The operational boundary is max(original receipt or retained document import boundary, review, actual ingestion). The server stamps actual ingestion/knownAt using its trusted clock, overriding earlier submitted times. New evidence is never made available at an earlier economic cutoff. Original retained input times remain unchanged.

Missing public publication evidence does **not** block this current-use time contract when all other source and semantic controls pass. It also never becomes invented publication evidence. Existing exact/canonical publication time validation is unchanged; default scoring callers and PIT paths reject the current-only contract. Full valuation readiness still depends on all mandatory selected facts and unchanged valuation contracts, not merely successful ingestion of a subset.
