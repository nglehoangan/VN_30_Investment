# HPG current-analysis qualification

The Owner request retained in `evidence/2026-10-14-hpg-decision-grade-closure/OWNER_REQUEST.txt` scopes this closure to HPG. Debt Contract v2, its measurement/lease policy, sector groups and historical replay semantics stay unchanged.

`hpg-current-decision-grade-qualification-v1` is an optional current-analysis evidence-pack version. Hybrid/manual admission accepts this pack only for the single HPG universe in CURRENT_ANALYSIS. The new ordinary-share profit proof binds the literal issuer EPS numerator, source-specific parent profit, fund/remuneration appropriations, source dimensions/hash and independent review witness. Provisional issuer appropriations remain visible. These are AS_REPORTED facts; they do not become normalized earnings. The pack has no qualified economic operating-profit definition, so operating labels or arbitrary line subtraction stay unadmitted.

A case-specific Risk Manager review may change the quantified opaque-population materiality state for current analysis. It retains every UNKNOWN component and amount, exact fractions and comprehensive-unverified status. It creates no universal materiality threshold, exhaustive debt proof, unrestricted cash or normalized EBITDA.

Qualified cash and normalized/downside EBITDA continue to use Debt Contract v2 guards and must match the independent reviewed analytical-witness inventory in this pack. Declared qualifiers cannot overrule a reviewed UNAVAILABLE conclusion. Normalization candidates retain reason, amount, period, source, classification, reversibility, confidence and admission status. An unadmitted gain-removal candidate is not a normalized EBITDA recipe.

Six-section current-analysis readiness requires qualified inputs and evidence-backed section assessments. Historical PIT readiness is reported separately and is never an automatic current-analysis gate. Data coverage alone does not grant decision-grade evidence or scoring readiness. DI14/DI15 and official scoring remain separate reserved gates.

Recompute only this pack with Node22: `node scripts/close-hpg-decision-grade.mjs`. After sealing, use an isolated `--out=/private/tmp/...` directory. Independently replay with `node scripts/verify-hpg-decision-grade.mjs`. Source review, known issuer attribution discrepancies, original versus comparative lineage and all closure results are retained in the evidence directory.
