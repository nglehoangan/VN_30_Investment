## Scoring specification

Version `vn30-five-rubric-amendment-v1.0`. The calculator branch reuses the public-data diagnostics. The amendment checks each method's explicit evidence dimensions. To produce a research proposal it requires exact subject, rubric and evidence digest, a pinned counter-evidence review and at least two sensitivity cases resolving to the same existing M3 anchor. Use the existing lower point for a conservative assessment and require the existing maximum prerequisites for a maximum-band proposal. Missing input or disagreement leaves null. A qualitative scoring interpretation must be reviewed for the exact evidence, rather than inferred from a numeric average of dimensions. The diagnostic one-percent denominator floor and assumed 20% tax are sensitivity controls, not point thresholds.
