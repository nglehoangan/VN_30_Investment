## Proposed tests for later phases — not executed here

- Identity: exact ledger ID and market UUID; code/ISIN/venue/class agreement; absence of ledger anchor; ambiguous/multiple/overlapping matches; ticker reuse/rename; missing ISIN without qualified alternate; FPT_UNAVAILABLE suffix; corporate-action successor; effective and knowledge cutoffs.
- Evidence and authority: modified bytes, changed hash/pointer, equal amount with wrong instrument, unknown schema, wrong portfolio/ticker/purpose/interval, missing owner/independent acceptance, producer self-approval, forged/local unsigned record, revoked/expired/superseded approval and stale cache/trust head.
- Price/time: all held coverage, missing/zero/negative/conflicting quote, halted/unavailable instrument, exact decimal limits and unit/multiplier errors, unfinished/future bar, capture after cutoff, policy-generated time versus provider time, holiday/weekend/exception closure, unknown calendar year, next-session boundary and clock rollback.
- NAV and separation: same-instant CASH/RECEIVABLE/PAYABLE/quantity, no receivable double count, ledger revision/change during read, later ledger activity versus EOD label, no excluded deferred/legacy holding, stale prices never zero-filled, synthetic tests never live NAV, NAV-only result cannot enter CurrentReadService.context, no D2/scoring/new-capital side effect.
- Operations: authenticated acceptance/audit replay, immutable source recovery and hash checks, revoke while rendering/cached, restore rollback detection, failed capture, restart and retry idempotency. No test creates production approvals.

## Authentication deferral and minimal operations

Ordinary local viewing, retained indicative research and future offline bridge/parser/arithmetic tests can operate without app login. Tests must use isolated data and explicit SYNTHETIC_TEST/PREPARATION labels; retained real evidence replay remains unaccepted. No private broker access credential is an owner/validator identity.

Do not install an identity provider, login UI or sessions to implement phases 1–2 later. Do not replace PEC-1C contracts with Mac usernames, Codex statements, signed-by-text fields, fabricated keys or unsigned JSON. The owner may keep authentication deferred indefinitely, in which case phase 4 and accepted current NAV remain blocked. Alternatively, a later separately approved operational authenticated workflow may satisfy the existing contracts without an app login; it must actually verify principals, roles, issuer/key trust, scope, trusted events, separation and revocation. No such workflow is selected or implemented here.

## Rollback and stopping rules

Future preparation versions are append-only and nonauthoritative. On source/hash/identity/calendar/clock/revocation failure, return null official NAV with exact blockers; retain original ledger/source evidence. Disable only the NAV display path if integration fails, preserving normal local portfolio/research views and existing production gates. Never repair a failure by changing ledger facts, zeroing a holding, granting approval, modifying a frozen policy or reverting to an older approved record over a newer conflict.
