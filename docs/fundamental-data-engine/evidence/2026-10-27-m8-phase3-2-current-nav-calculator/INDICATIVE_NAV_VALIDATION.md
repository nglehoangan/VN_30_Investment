# Indicative Nav Validation

Date: 2026-10-27. Scope: Phase 3.2 isolated implementation only.

Indication is research only and explicit opt-in. Missing formal proofs alone may allow it when observations are complete, identity exact, prices fresh/coherent, economic components known and no source conflicts. Revoked/expired/invalid/scope-mismatched proof is a hard failure, not an excuse to downgrade. Unknown liability, unresolved claims, pending rights or missing held price blocks full indication.

INDICATIVE_NAV has totalNav=null and a separate exact indicativeValue. QUALIFIED_ONLY never downgrades, even when allowIndicative=true. All operational permissions remain false in every state. Partial supported components can produce a named securities subtotal with exclusions; that amount is not portfolio NAV or a performance/risk input. Actual portfolio remains blocked; no research amount was fabricated from broker records.
