## 6. Approved decision matrix

| Condition | Latest valid assessment | Current-purpose score | Update disposition |
|---|---|---|---|
| Supported new assessment | Replace with new qualified assessment | New score | UPDATED |
| Current evidence independently confirms same band | Preserve qualified score | Valid score | REAFFIRMED |
| Existing inheritance criteria satisfied | Preserve qualified score | Valid inherited score | CARRIED_FORWARD |
| New data insufficient, no material invalidation established | Preserve historical score | Unconfirmed or N/R | UPDATE_PENDING |
| MATERIAL_IMPACT_UNRESOLVED | Preserve historical score | Unconfirmed or N/R | MATERIAL_REVIEW_PENDING |
| MATERIAL_INVALIDATING | Preserve historical record only | N/R unless replacement supported | INVALIDATED |
| Expired evidence | Preserve historical record only | Not eligible | Reassessment required |
| New authoritative annual data available | Preserve historical record pending reassessment | Apply freshness and replacement rules | Reassessment required |
| No valid historical or current assessment | No numeric score | N/R | Not rated |

A valid new assessment takes precedence over an obsolete pending state.

A supported material invalidation takes precedence over a pending classification when no valid replacement exists.

Do not fabricate current scoring eligibility from the historical score.
