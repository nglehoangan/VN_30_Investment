## 4. Approved BQ-EQ evidence contract

### 4.1 Returns — CORE

Require economically meaningful evidence of returns on capital.

Permitted routes:

- Normalized ROIC.
- Sustainable ROE or ROTE for applicable sectors.
- Existing approved sector-equivalent return metrics.
- Defensible conservative return ranges.
- Approved combined economic evidence when direct ROIC is unavailable.

The selected return method must remain economically meaningful and suitable for the issuer's sector.

Do not permit raw ROE alone to substitute automatically for industrial or technology ROIC.

### 4.2 Persistence — CORE

Require sufficient historical evidence to evaluate the durability of economic returns.

Use three-year history where five-year history is unavailable, consistent with existing M3 rules.

Prefer FY2022–FY2025 for the FPT pilot.

Evaluate:

- Stability of normalized economic returns.
- Historical profitability.
- Material abnormal periods.
- Structural changes.
- Sustainability of economic performance.

Do not invalidate a supported historical assessment merely because newer quarterly information exists.

Reassess it when new information materially affects the economic conclusion.

### 4.3 Margins — SUPPORTING / CONDITIONAL

Margin evidence is supporting by default.

Use available gross margin, EBIT margin, sector-equivalent operating profitability and historical margin trends.

Missing standalone margin evidence must not automatically cause N/R if the remaining evidence sufficiently supports the selected band.

Margin evidence becomes a necessary dependency when:

- Material margin deterioration may invalidate the selected return assessment.
- Reported return metrics conflict with operating performance.
- Margin normalization is essential to the selected return method.
- The selected band or existing maximum-score prerequisites require durable superior profitability.

Assess and document materiality explicitly.

Do not ignore contradictory margin evidence.

### 4.4 Cost of capital — CORE, estimate permitted

Permit a reasoned analyst estimate or conservative range.

Use an appropriate economic hurdle:

- WACC for ROIC-based assessment.
- Cost of equity for ROE/ROTE-based assessment.
- Compatible sector-equivalent hurdle where applicable.

Record:

- Method.
- Input assumptions.
- Supporting public evidence.
- Estimate range.
- Sensitivity.
- Relevant limitations.

Do not require issuer-confirmed WACC or an externally published exact cost-of-capital value.

Do not confuse the portfolio target return with the company's economic cost of capital.

### 4.5 Peer comparison — SUPPORTING

Use peer comparisons when useful and economically comparable.

If a reliable peer group is unavailable, use approved absolute economic anchors and own-history analysis.

Missing peer comparisons alone must not block BQ-EQ.

Preserve existing sector normalization and small-peer-set controls.

### 4.6 Maximum-score requirements

Preserve all existing maximum-score prerequisites.

An 8/8 result requires documented durable superior economics, exceptional justification and valid disconfirming evidence review.

High returns caused by leverage, undercapitalization, weak provisioning, temporary accounting effects or abnormal cycle conditions must not automatically receive maximum credit.

## 5. Approved fallback order

For BQ-EQ, implement the following sequence.

### Route A — Direct return calculation

Calculate normalized ROIC or the applicable primary sector return measure from admitted financial evidence.

### Route B — Sector-equivalent return

Use an approved economically equivalent return measure when the primary metric is unsuitable or unavailable.

Explain the equivalence.

### Route C — Conservative range

Construct defensible return and cost-of-capital ranges using supported public operands and justified assumptions.

Determine which economic assessment remains defensible across the relevant range.

Do not invent missing financial values.

### Route D — Combined economic evidence

When direct ROIC cannot be reliably calculated, assess whether a combination of evidence can establish the same economic conclusion.

Possible components:

- Normalized ROE.
- Leverage-adjusted profitability.
- Historical ROIC.
- Operating margin.
- Capital efficiency.
- Asset turnover.
- Operating cash realization.
- Comparable segment-level returns where available.
- Evidence concerning material changes in business scope.

The combined evidence must establish an economically meaningful conclusion about returns relative to the appropriate cost of capital.

Address material conflicting evidence.

This is an authorized BQ-EQ substitution route, not permission to infer a score from arbitrary unrelated ratios.

### Route E — N/R

Assign N/R only after the relevant authorized routes have been attempted and no defensible existing band remains.

State the precise economic uncertainty that prevents assessment.

Do not assign zero or a low score merely because information is missing.

## 6. Preserve existing scoring bands

Keep the exact existing registry bands:

| Assessment | Allowed points |
|---|---|
| Value destructive | 0 |
| Weak economics | 1–2 |
| Average economics | 3–4 |
| Good economics | 5–6 |
| Consistently superior economics | 7–8 |

Apply the following assessment principles:

- 0: Evidence establishes persistent value-destructive economics.
- 1–2: Weak return economics or material economic limitations.
- 3–4: Average economics without adequately demonstrated durable superiority.
- 5–6: Good sustainable economics supported by returns relative to economic cost.
- 7–8: Consistently superior economics supported by strong historical and normalized evidence.

Preserve existing within-band stronger-evidence requirements.

When only the lower point of a defensible band is supported, explicitly select that lower point.

Do not automatically assign the lowest band because the evidence is incomplete.

No new hard numerical thresholds are authorized beyond existing approved economic anchors.
