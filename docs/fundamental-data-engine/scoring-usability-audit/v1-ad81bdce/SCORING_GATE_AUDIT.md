M3 §9 missing-not-zero and no weight redistribution remain mandatory. A defensible conservative estimate/range is allowed only with bounded evidence; the engine's complete-total rule must not be bypassed by synthetic partial sums. Distinguish a stricter formal implementation from permission to change approved scoring authority: proposals need separate review and parity tests. Formal evidence requires available, compatible publication/PIT provenance; evidence.ts supports date-only v2 policy, so timestamp precision is not universally mandatory. Publication unknown is not invented. Existing authority baselines stay approved; draft headings in historical design docs do not revoke accepted runtime methodology. All gates above are static audit findings, not executed full-engine regression tests.
