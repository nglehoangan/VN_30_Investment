## 24. Economic transfer model

Reuse existing approved CA-DIL formulas.

Let:

N = pre-issue economically equivalent shares.

n = newly issued economically equivalent shares.

V = pre-issue economic value per share.

C = net incremental proceeds.

B = incremental net economic benefits not already reflected in V.

Post-event value:

(N × V + C + B) / (N + n).

Economic per-share loss:

1 − post-event value / V.

Break-even benefit:

n × V − C.

Extend the model appropriately for:

- Treasury shares.
- Transferable rights.
- Lock-up.
- Forfeiture or repurchase conditions.
- Compensation costs.
- Economic ownership changes.

Do not count the same compensation expense or benefit twice.
