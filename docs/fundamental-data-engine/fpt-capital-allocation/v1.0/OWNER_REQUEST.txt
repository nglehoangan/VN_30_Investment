## 21. Economic dilution calculations

For a simple new-share issuance with no separate rights value:

Let:

- N = pre-event economically equivalent shares.
- n = new economically equivalent shares.
- V = pre-event economic value per share.
- C = net incremental proceeds.
- B = incremental net economic benefit not otherwise reflected.

Pre-event equity value:

N × V.

Post-event equity value:

N × V + C + B.

Post-event value per share:

(N × V + C + B) / (N + n).

Per-share economic loss:

1 - post-event value / V.

Break-even incremental benefit:

n × V - C.

Use appropriate extensions for treasury shares, transferable rights, participation costs and mechanical capital actions.

Do not apply the simple formula to transactions where it is economically inappropriate.

Record whether the model uses gross or net proceeds.

Do not silently assume fees are zero.

Include compensation expense and benefits once.

Do not add back compensation expense already reflected in the chosen economic value without justification.
