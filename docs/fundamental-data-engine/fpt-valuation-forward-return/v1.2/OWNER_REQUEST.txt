## 9. Band eligibility rules

### Case A — Qualified range within a single band

If all economically admissible outcomes in the qualified range fall within one canonical band:

- Permit an analyst proposal within that band.
- Apply the existing confidence and evidence requirements.
- Apply Method A ceiling.
- Preserve adjacent-band rationale.

Illustrative examples:

- Qualified IRR range 3%–7%: eligible for band 0–1.
- Qualified IRR range 9%–11%: eligible for band 2–3.
- Qualified IRR range 12.5%–14.5%: eligible for band 4–5.

These are synthetic examples, not FPT conclusions.

### Case B — Qualified range spanning multiple bands

If the range crosses canonical bands:

- Review whether an explicitly conservative base case is independently qualified.
- Review whether the evidence supports a conservative return conclusion under existing M3 methodology.
- Document why the selected band remains economically defensible.

Do not automatically choose the lowest band merely because a severe stress case exists.

Do not automatically choose the highest band.

Do not use the midpoint of an IRR range without economic justification.

Do not invent scenario probabilities.

If no defensible expected-return conclusion exists, return N/R.

### Case C — Sensitivity-only range

If the underlying range is sensitivity-only:

- Retain the numerical outputs.
- Retain scenario limitations.
- Do not authorize a score solely because every displayed sensitivity happens to fall within one band.

### Case D — Low qualified IRR

A supported low or negative expected IRR is an eligible economic conclusion.

Do not convert it to N/R because it fails the investor return objective.

Distinguish zero points from missing assessment.
