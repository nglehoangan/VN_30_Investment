## 11. Valuation Assumption Qualification Framework

VA15 is a central implementation requirement.

Implement a reusable, versioned qualification contract.

Reuse existing assumption and provenance structures where possible.

Do not create a duplicate parallel registry if an equivalent architecture already exists.

### 11.1 Qualification statuses

FACTUAL:

Directly supported by eligible factual evidence.

QUALIFIED_ESTIMATE:

Analyst estimate with adequate economic justification, eligible evidence and bounded uncertainty.

BOUNDED_ESTIMATE:

A supported range or explicitly conservative estimate with material limitations and appropriate sensitivity review.

SENSITIVITY_ONLY:

Exploratory assumption used only to understand model behavior.

UNSUPPORTED:

Assumption without adequate economic basis.

INVALIDATED:

Assumption contradicted or invalidated by eligible evidence.

Keep evidence type separate from qualification status.

Evidence type may be FACT, DERIVED, ESTIMATE or ASSUMPTION.

A derived value is not automatically qualified for valuation.

## 14. Owner Earnings, DCF and cross-check

### 14.1 DCF mechanics

For an equity cash-flow valuation:

Value = PV of forecast equity cash flows + PV of terminal equity value.

For a Gordon terminal model:

Terminal value = final-year sustainable cash flow × (1 + terminal growth) / (discount rate − terminal growth).

Require discount rate greater than terminal growth.

Use sustainable terminal assumptions.

Report the contribution of terminal value to total valuation.

Review excessive dependence on terminal value.
