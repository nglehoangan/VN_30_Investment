# UI, accessibility and performance evidence

Desktop 1440px and mobile 390px browser captures cover dashboard, holdings, VN30, ranking, scorecard, decision, DCA, all review cadences, journal, transactions/entry/confirmation, audit, data status, risk, performance, settings and review initiation. All major pages assert a heading, explicit BLOCKED status for synthetic current sources and no document-level horizontal overflow. Artifact inspection remains historically available. Empty/error/blocked/stale/success/loading states are covered by UI/current unit and integration suites; browser tests additionally exercise successful explicit contribution confirmation and blocked formal review initiation. Browser fixtures are not a real-data operational acceptance session.

Keyboard tests exercise skip-link visible focus (3px outline), content focus, keyboard form submission, associated invalid-date error, semantic column headers and keyboard-focusable scrolling table at both widths. The confirmed skip target lacked tabindex; the content target now has tabindex=-1. Browser focus checks wait for streamed content to be visible before native skip-link activation; diagnostics showed an attached target with no layout was being activated prematurely. The native link and focus assertion remain intact. Screenshots were inspected at both widths. Mobile navigation and nested table/evidence scrolling remain dense but readable; exact values and status text are preserved. Status is expressed in words rather than color alone; labels and errors remain associated with inputs. Automated checks and visual inspection do not constitute a complete assistive-technology certification.

The UI exposes proposal versus executed transaction, economic decision versus execution feasibility, evidence as-of/cutoff, stale/unreconciled status and synthetic warnings. No urgency timer, forced contribution allocation, gain-triggered SELL, price-triggered averaging, rank-as-BUY, casino animation or policy-changing annual action is added. Confirmation remains explicit and separate from preview/proposal.

performance.json records five timed current captures over 30 held securities and 31 immutable ledger events. This is measured local VN30-scale evidence, not a production SLA or a large-history benchmark. Source audit finds five full ledger reads per current capture (reconstruction/valuation and snapshot validation). Monthly initiation also verifies the complete marginal body-hash inventory before selection, preventing corrupt selection metadata from hiding authority. Full-history reads and large immutable embedded artifacts remain real maintenance debt; query limits on UI catalogs avoid unbounded catalog rendering but do not solve historical reconstruction. No Redis, microservice or speculative caching was added. No correctness failure or material local slowdown appeared at the measured scale. See the JSON for final observed timings.
