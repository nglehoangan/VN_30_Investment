# ADR 0005 — Local authentication deferral

Date: 2026-10-24. Current instruction: **DEFERRED_BY_OWNER**.

The application runs locally on the owner's personal Mac. No login/authentication implementation is commissioned now. Google OIDC is deferred to a future separately authorized milestone. Preserve Next.js, Prisma and SQLite and keep ordinary portfolio viewing and analysis available under existing data integrity/actionability rules.

This supersedes PEC-1D's immediate provider-selection recommendation. It does not approve a new local identity system or waive authenticated source authority, independent acceptance, formal knowledge, production admission, D2 or scoring gates. PEC-1C contracts remain unchanged for future integration. Never substitute OS username, local JSON, unsigned records or Codex output for authenticated approvals.

No libraries/providers, screens/sessions, identities, database migrations or scoring activation are authorized. See [the versioned amendment](../fundamental-data-engine/evidence/2026-10-24-pec1d-authentication-deferral-amendment/CLOSURE_REPORT.md) and [current decision](../fundamental-data-engine/PEC1D_CURRENT_DECISION.md). The sealed original PEC-1D report remains immutable history. Amendment is awaiting owner review; no source approval is created.
